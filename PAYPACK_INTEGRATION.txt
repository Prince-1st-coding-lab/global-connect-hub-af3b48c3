ONE-TIME SETUP YOU MUST DO
--------------------------
1. Add two Edge Function secrets in your Lovable project:
       PAYPACK_APP_ID            (from https://dashboard.paypack.rw)
       PAYPACK_WEBHOOK_SIGN_KEY  (your chosen signing key, same value
                                  you paste into Paypack's webhook UI)
2. In the Paypack dashboard, register the webhook URL:
       https://qzfnzphbllhyyiyygaiy.functions.supabase.co/paypack-webhook
   Paypack will send a HEAD probe first — the function returns 200.
3. In /admin → Payment Links, create entries with the amounts you
   want customers to pay. Each entry shows in the booking dialog and
   triggers Paypack with that exact amount. The `url` field is no
   longer used by the booking dialog (kept for backwards compat).

HOW THE FLOW WORKS
------------------
Customer clicks a payment link in BookingDialog
  → supabase.functions.invoke("initiate-paypack-checkout", { amount, item_name, email })
  → edge function inserts row in `orders` (status=pending) with a
    UUID session_id, then POSTs to Paypack /checkout/initiate
  → Paypack returns { payment_link }
  → browser is redirected to Paypack's hosted page (new tab)
  → on payment, Paypack POSTs an HMAC-signed event to
    /functions/v1/paypack-webhook
  → webhook verifies the signature and flips the order's status
  → user lands on /payment-success or /payment-cancelled
